⚙️ Preprocessing Techniques

1

Missing Value Handling

Numerical missing values are replaced using the median, while categorical missing values are replaced using the mode.

2

Duplicate Removal

Duplicate records are identified and removed to avoid repeated observations.

3

One-Hot Encoding

Categorical input variables are converted into numerical representation using one-hot encoding.

4

Standard Scaling

Numerical input features are standardized using StandardScaler so that they are placed on a comparable scale.

Scaling Method StandardScaler
