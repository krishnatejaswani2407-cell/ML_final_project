IQR Formula

IQR = Q3 − Q1
Lower Fence = Q1 − 1.5 × IQR
Upper Fence = Q3 + 1.5 × IQR

MonthlyIncome values above the upper fence are handled using clipping instead of deleting employee records.

3. Feature Engineering

Creating New Features

New features are created from existing employee attributes to help the machine learning models identify useful patterns.

New Feature Created From Purpose
AgeGroup Age Groups employees according to age.
ExperienceGroup TotalWorkingYears Groups employees based on total work experience.
TenureGroup YearsAtCompany Represents employee tenure in the company.
OverallSatisfaction JobSatisfaction + EnvironmentSatisfaction + RelationshipSatisfaction + WorkLifeBalance Represents overall satisfaction.

Preprocessing Summary

The SkillMatch dataset is cleaned by removing unnecessary columns and missing values. MonthlyIncome outliers are handled using IQR clipping. New employee features are created, Attrition is encoded as 0 and 1, and the data is prepared for model training and testing.
